# 我们的小屋 · Our Little Home

送给嘟嘟的生日互动小屋。一间可以走动、读信、休息的小屋，还有随四季与昼夜变化的海边。

[在线体验](https://our-little-home.glossy-pearl-2145.chatgpt.site/)

## 功能

- 点击或触摸地面移动，也支持方向键、WASD 与 E 键互动。
- 小屋与海边两个场景，四季、昼夜循环，以及八张海边背景。
- 生日信、礼物、NPC 祝福、沙发休息、睡觉、秋千、看海和贝壳收藏。
- 可选的合成环境音、视野调整、全屏和手机适配。
- 收藏保存在当前浏览器本地；无需登录，没有后端，也不需要 API 密钥。

这是单人体验，男孩角色使用预设对话，不代表其他访客实时在线。

## 本地运行

无需安装依赖或构建。安装 Python 3 后，在项目根目录执行：

```sh
python3 -m http.server 8000 --directory dist
```

然后访问 http://localhost:8000 。也可以用其他静态 HTTP 服务器托管 `dist/`。

## 检查

安装 Node.js 后执行：

```sh
node --check dist/app.js
node --check dist/content.js
node scripts/check.mjs
```

检查包括脚本语法、互动地点之间的寻路、时钟边界和场景素材完整性。

## 修改内容

| 文件 | 内容 |
| --- | --- |
| `dist/content.js` | 生日信、礼物文案、NPC 对话与时钟起点 |
| `dist/app.js` | 游戏逻辑、寻路、绘制和互动 |
| `dist/style.css` | 页面布局和样式 |
| `dist/index.html` | 页面结构 |
| `dist/assets/` | 背景、人物与动作素材 |

当前版本保留原网站的生日信与祝福。复用时可以在 `dist/content.js` 替换为自己的内容。

昼夜各持续 60 秒，五个完整日夜进入下一个季节，全年循环约 40 分钟。时间依据固定起点计算；切换场景或刷新不会重置。修改 `clockEpoch` 会改变循环起点。小屋花园通过色调和粒子表现季节，海边使用八张独立画面。

## 静态托管

把 `dist/` 目录发布到静态托管服务即可。所有游戏素材均随仓库提供，资源路径为相对路径。
